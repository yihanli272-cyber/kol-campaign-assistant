# AI KOL Campaign Decision Assistant

通用 KOL Campaign 决策工具；PETKIT 为默认示例，并非品牌定制或官方项目。已完成 Campaign 输入、筛选与评分、预算内组合优化、效果估算、基准情景比较和 CSV 下载，并支持独立真实候选池与模拟参数。默认仍使用原有 30 条固定模拟数据。采用简体中文业务界面和中文开发说明；不调用 AI API。

## 本地启动（Windows PowerShell）

在项目根目录执行；已有 `.venv`，无需重建。解释器实际位于项目内 `.venv`，不是父目录。

```powershell
cd D:\AI_Projects\kol-campaign-assistant
.\.venv\Scripts\python.exe -m streamlit run app.py --server.headless true
```

浏览器打开 http://localhost:8501 。在运行服务的终端按 `Ctrl+C` 停止。若 8501 已被占用，可追加 `--server.port 8502` 并访问对应端口。

修改多个 Python 模块后若出现“文件中明明有常量但 cannot import name”的错误，应先停止旧 Streamlit 服务再用上述虚拟环境命令启动。长期运行的服务可能仍保留旧模块；仅刷新网页不等于重启 Python 进程。不要通过重复定义版本号或添加自动 reload 来掩盖问题。HTTP 200 和健康接口只证明服务可访问，仍需检查页面脚本是否实际执行成功。`tests/test_startup.py` 额外在全新 Python 进程中核对本地导入名称、版本与 CSV 一致性，并执行两种数据集页面。

依赖已锁定为当前安装的 Streamlit 1.66.1、pandas 3.1.0；本地验证 Python 3.13.17。仅在新环境需要安装：

```powershell
python -m pip install -r requirements.txt
```

## 数据、评分与限制

全部创作者名称（带 SIM 标识）、粉丝数、受众、报价、触达、互动、内容质量、CTR、CVR 都是模拟值，不是真实账号或历史投放结果。`data_type=simulated`，版本 `phase1-v1`。互动率以触达为分母，CSV 用小数比率（0.05 = 5%）；分数为 0–100，费用为 USD。内容质量为预设评分，未对真实视频进行 AI 审核。

按报告采用三套权重（受众/触达/互动/质量/效率）：Awareness 30/35/10/15/10%，Engagement 25/10/30/15/20%，Conversion 30/5/5/20/40%。归一化固定范围，不随筛选结果变化；同分按 creator_id 排序。原始分、权重贡献、公式和效率上限可在页面展开查看。

模型简化：受众调整触达 = 单条内容触达 × 受众匹配分 / 100；美国地域和标签匹配尚未独立建模。效率分按目标使用调整触达、模拟互动或模拟转化除以合作费。固定上限为产品假设，不是行业基准。单人评分保持第一阶段口径；组合优化单独计算执行总成本。

品牌、产品和市场输入当前为展示标签，改名不会自动改变匹配分。样本适用于美国宠物科技示例；跨市场、跨行业必须先人工核实或替换匹配假设。默认 $5,000 是模拟预算。累计触达未去重；模型不证明因果关系或收益，不计算真实 ROI。

## 第二阶段算法与公式

0/1 背包动态规划精确比较组合，最多选 6 人，预算上限 $10,000，最多 30 条候选。费用按整数美分计算，每位创作者只使用一次；目标分别最大化累计受众调整触达、互动、转化，不按粉丝数或单人评分依次贪心选人。同效果优先低成本，再按 ID 固定顺序选择。缺失、无效字段或重复 ID 的记录不会入选，页面返回原因。空结果安全返回零活动与 N/A 单位成本。

- 单人执行成本 = 合作费 + 每人样品成本 + 每人物流成本。后两项可在侧栏修改，默认 $0 仅为占位假设。
- 预算使用额 = 所选创作者执行成本合计；剩余 = 预算 − 使用额。费用不含税、内部人力或付费放大。
- 互动 = 受众调整触达 × ER；点击 = 受众调整触达 × CTR；转化 = 点击 × CVR。CSV 已有逐人模拟 CTR 和 CVR，不增加新数据源。
- 组合预测指标逐人相加。粉丝数、单条触达、组合累计触达分别展示；累计触达不去重，转化可为小数，不是实际订单。
- CPM = 使用额 / 受众调整触达 × 1000；CPE/CPC/CPA = 使用额 / 对应互动、点击、转化。分母为零时显示 N/A。
- 优化不建模受众重叠或平台多样性；高分创作者不一定入选。推荐理由为程序模板，说明目标贡献、成本和约束。

### 功能验收

1. 打开本地页面，以默认 $5,000 在“Campaign 总览”查看摘要；到“投放组合优化”核对名单和支出，到“报告与导出”展开公式。
2. 在“情景分析”点击“保存当前方案为基准方案”，将侧栏预算改为 $3,000，查看重算的组合、变化表和新增/退出 ID；基准保持原样。
3. 预算不变时页面明确说明同一情景。改目标或筛选时列出变化字段，不误称为仅预算变化；数据或模型版本变化会要求重存基准。基准只保留在当前会话，刷新/新会话不保证保留。
4. 将预算设为 0 或清空平台，确认无可行方案提示、零预测、N/A 单位成本和下载入口消失；与基准比较时不会把零活动解释为效率提升。
5. 恢复可行预算，在“报告与导出”点击“下载当前组合 CSV”。用 Excel 打开核对 ID、费用、评分、选择理由、逐人预测和预算总额。编码为 UTF-8 BOM；`portfolio_*` 是每行重复的组合总额，不能再次相加。无方案时不能导出。

变化表使用 当前 − 基准 的绝对差与百分比；基准为零或单位成本不可计算时百分比留空。比较同时展示两套输入，样品、物流、目标和筛选变化均显式提示。

## 后续范围与部署计划

### 真实候选池与模拟模型的边界

侧栏 `Dataset` 可选 `Simulated Demo Dataset`（默认）或 `Real Creator Research Dataset`。原 `mock_kols.csv` 原样保留，预算优化动态规划算法未重写。

真实候选池从当前会话的已批准 30 账号报告转录，以 `REAL001`–`REAL030` 为固定内部 ID；两张新表按 ID 一对一关联，不能按行号关联，也不能随意重编号。账号链接可追溯不表示当前免登录可访问；`partially_verified` 不表示可联系、可预订或具有美国多数受众。报告的 A/B 层级原样保留，B 也有二手证据限制。

公开资料表保存身份、主页、来源、日期、公开观测、核验状态、合作线索及人工复核项；`fit_rationale` 与内容分类是研究者判断。模拟报价、触达和模型率不得写入这张表。缺失值留空，CSV 再读后为缺失值，不填 0。

粉丝数分为 `followers`（具有明确测量日的快照，本次只有 Rigby）与 `reported_followers`（报告中第三方页面近似值，单项测量日未知）。页面日期保存为 `source_data_date` 并由 `source_date_basis` 注明含义。不能将页面更新日当作所有指标的测量日。近期第三方内容记录链接放 `recent_content_source_url`；没有取得原帖时 `recent_post_url` 留空。美国受众比例是第三方估计而非本人后台；所在地、语言和国家排名不作替代证据。

| 独立来源字段 | 进入原计算接口的字段 | 含义 |
| --- | --- | --- |
| 公开表 `creator_id`、姓名、平台、分类 | 同名字段 | 身份资料；分类为研究者判断 |
| 公开表 `followers` | `followers` | 可缺失，仅用于筛选，不参与效果预测 |
| 参数表 `estimated_fee_usd`、`estimated_reach` | 同名字段 | 模拟报价与模拟单条触达 |
| 参数表 `assumed_engagement_rate` | `engagement_rate` | 以调整触达为分母的模拟模型互动率 |
| 参数表 `assumed_ctr`、`assumed_cvr` | `assumed_ctr`、`assumed_click_to_purchase_cvr` | 模拟点击率和点击后转化率 |
| 参数表 `assumed_audience_match_score` | `audience_match_score` | 模拟分数预设，不等于美国受众占比 |
| 参数表 `assumed_content_quality_score` | `content_quality_score` | 模拟分数预设，不表示实际审核过视频 |
| 公开表 `observed_engagement_rate`、`visible_views`、`us_audience_share` | 仅保留元数据 | 不转换成模型互动率、预测触达或匹配分 |

每个参数有对应的 `*_source` 说明；版本为 `research-planning-v1`。数值全部是本阶段明确编写的演示假设，没有从公开历史指标推导，也没有把原模拟创作者的表现直接移植到真实身份。

只有 Mochi、Yuki Bunny、Ashley、Casper & August、Louie 这 5 个有喂食器/设备历史内容线索的账号启用标准模板：每人报价 $500、触达 20,000、ER 5%、CTR 2%、CVR 2%、匹配与质量分均 70。相同的圆整数值是刻意的场景预设，不声称能区分真实创作者优劣，不表示真实报价、可签约或已测量的内容质量。其余 25 行关闭建模，参数留空，并记录暂缓原因。

进入预算计算必须同时满足：有对应的假设记录、`model_enabled=true`、所有必要参数有效、逐参数来源及版本完整。禁用、缺失或无效的参数均阻止入选并显示原因。未知粉丝数不是数字 0：筛选最小粉丝数为 0 时保留未知；正阈值会排除未知值。所有真实候选均须在实际投放前人工核实。

内部计算行显式标识 `data_type=hybrid_public_identity_simulated_model`、`identity_data_type=public_profile`、`model_data_type=simulated`、`numeric_score_basis=simulated_preset`。原来的纯模拟校验仍严格要求数值完整。计算结果与导出保留公开字段、研究解释和模拟来源说明，不把身份标为虚构，也不把模型值标为真实。

两种数据集各保存一个独立基准；研究表和参数表任意记录变化都会改变研究指纹，旧基准要求重存。CSV 仍为 UTF-8 BOM，研究模式文件名以 `research_identity_simulated_model_` 开头。
