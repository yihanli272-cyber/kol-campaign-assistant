# 公开账号库与独立规划数据

本目录的5份CSV为应用运行所需数据，文件清单见根目录 `release_whitelist.txt`。账号资料共52条：Instagram 20、TikTok 20、YouTube 12。按稳定内部ID和平台关联，不合并跨平台同名账号。

- 账号CSV：公开资料、历史报告指标及可追溯元数据；不是实时监测或实际投放效果。
- 审核CSV：原始待审核状态，不包含审核人员信息，不授予正式资格。
- 内容证据CSV和独立假设CSV：保留必要结构，当前为空；不虚构原帖或已批准假设。
- 补充CSV：已有匹配度和补充观察；两条匹配度存在，其余保持空值，不将匹配度作为转化概率。

运行时Simulation参数保存在根目录独立JSON中，不覆盖历史指标。CSV为UTF-8 BOM，空值代表缺失，0仅代表实际记录的零；请通过 `creator_registry.load_registry()` 读取，避免长账号ID被表格软件转换。

原始Excel、私人联系方式、派生研究文件和人工审核日志仅保留本地且不在发布白名单中。公开模式不加载本地审核日志，也不允许写入。需要本地审核时由受信任开发者启用 `local_dev`；此功能不是公共多用户审核系统。
